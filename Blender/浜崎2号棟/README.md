# 浜崎2号棟 Blender モデル (PoC)

朝霞市浜崎3丁目全2区画 2号棟(ランドスタイル一級建築士事務所・R8.7.7竣工予定)の実行図PDFから、
Blender headless + bpy で起こしたパラメトリック3Dモデル。Alex Albert の「土地写真→設計→Blender headless→ウォークスルー」投稿
([調査レポート](../../Research/Blender×LLMコード生成ウォークスルーの調査.md))の、**図面忠実版**の検証。

## 使い方

```bash
# モデル生成 + .blend 保存のみ
/Applications/Blender.app/Contents/MacOS/Blender -b -P build_house.py

# 全カメラをレンダー (Cycles / Metal GPU, 1280x720)
/Applications/Blender.app/Contents/MacOS/Blender -b -P build_house.py -- --render --samples 64

# 1カメラだけ
/Applications/Blender.app/Contents/MacOS/Blender -b -P build_house.py -- --render --cam Cam_南西_外観 --samples 48
```

- 出力: `浜崎2号棟.blend`(GUIで開いて手直し可)/ `render/*.png`
- 環境: Blender 5.2.1 LTS / Apple M1 8コアGPU で 1枚あたり 1.5〜2.5分(64サンプル・デノイズあり)

## 簡略化・要確認 ⚠️

- 窓の位置は開口番号(1)〜(26)のサッシ呼称(例 16505 = W1,650×H500)から高さ・幅を取り、**壁上の位置は画像から目視で概略配置**。正確な位置はクロス貼り分け図のベクターから再抽出できる
- 1F 床面積 43.47 > 建築面積 42.23 の矛盾(ガレージ西張出し 910 が建築面積から除かれている)は図面の表記どおりに再現しただけで、法的解釈は未確認
- 外壁の内側面は面の法線で判定して内装クロス(車庫内は仕様どおり木目)に切り替えている。階段・建具・キッチン・UB は未配置(家具は箱の当たりのみ)
- 外壁・屋根・砂利・アスファルトはノードの手続きテクスチャ(外部素材なし)。サイディングは働き幅 455 の目地 + 細リッジをバンプで表現。写真並みにするなら BlenderKit/Poly Haven の PBR テクスチャに差し替える
- 敷地(14.55×5.67)・道路(幅員 10.6)・歩道・側溝・白線・CB塀+メッシュフェンスは配置図から概略。**隣家は置かない**(2026-09-06 の指示)。周囲は芝地に株立ちの道路沿いの低木・ポーチ北の植栽枡(販促ビジュアルのイメージ合わせ。実際の周辺環境とは異なる)
- 太陽は南西上空の固定値。日照シミュレーションにするなら Sun Position アドオン(緯度 35.79 / 経度 139.56)に置き換える

## 外観ディテール(実装済み)
破風・鼻隠し・軒樋・竪樋・胴差水切り・土台水切り・窓の水切りと召し合わせ・給湯器(東)・ポスト・ポーチ天井(木)・バルコニー笠木。
カメラは道路上に置く(隣地に入ると隣家で遮られる)。外観の写真は `Cam_南西_外観` / `Cam_道路_北西` / `Cam_ガレージ正面` / `Cam_俯瞰_南東`。

## 夕景 (--dusk)
`--dusk` を付けるとブルーアワー(濃紺の空・弱い残光)に切り替わり、室内灯と外構照明が点く。出力名に `_夕景` が付く。
- 外構照明: ポーチDL・玄関ブラケット・車庫天井DL×2・バルコニー下DL×2・外壁アップライト×4・植栽枡のフットライト×3・3Fバルコニー灯。器具本体は発光マテリアル
- 土間とアスファルトは夜だけ粗さを下げ、灯りが映り込む「濡れた」見え方にしている
- 露出: 外観 +0.4 / 内観 -0.6 (昼は -0.3 / +1.8)
- 動画も `--animate --dusk` → `SUFFIX=_夕景 ./make_video.sh` で `render/roomtour_20s_夕景.mp4`
```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P build_house.py -- --render --samples 96 --cam Cam_南西_外観 --dusk
```

## ルームツアー動画 (--animate)

外観一周(6s)→1F車庫(2s)→1F玄関(2s)→2F LDK(5s)→3F洋室A(5s) の5ショット。Eevee・1280×720・24fps。

```bash
# 各ショットの始点・終点だけ試写 (10枚・約10秒)
/Applications/Blender.app/Contents/MacOS/Blender -b -P build_house.py -- --animate --anim-test
# 本番 (480フレーム。M1 で 10〜15分)   --shot 04 で1ショットだけ
/Applications/Blender.app/Contents/MacOS/Blender -b -P build_house.py -- --animate
# 連番PNG → mp4 (0.5秒クロスフェードで結合)
./make_video.sh
```

- ショットの定義は `build_house.py` 末尾の `SHOTS`(秒数・レンズ・露出・カメラ座標と注視点のキー)。座標を足せばショットが増える
- 階段は歩かず、階の切替はフェード。玄関ドアは開いた状態で固定
- カメラが通る間仕切りにだけドア開口を開けている(`door(...)`)。ガラスは Eevee で透けるようアルファ 0.25
- 連番PNG(`render/anim/`)は git 対象外。mp4 だけコミット
