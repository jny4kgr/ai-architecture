## 1. 従来型パイプライン: CAD/BIM → リアルタイムレンダラー

### 定番構成

```
SketchUp / Revit / Archicad / Rhino / Vectorworks(3Dモデリング)
        │ LiveSync / プラグイン直結
        ▼
リアルタイムレンダラー(D5 Render / Twinmotion / Enscape / Lumion)
        ▼
静止画パース(4K) + ウォークスルー動画(カメラパス指定) + VR/360°
```

- リアルタイム系(D5/Lumion/Enscape/Twinmotion)は操作中に結果が即時更新され、提案・動画・VRに強い。オフライン系(V-Ray/Corona)は静止画の最終品質特化 ⚠️
- Enscape は Revit 等のプラグインとして動き、モデル変更が即レンダリングに反映(図面との整合性が最も取りやすい) ⚠️
- 動画機能: Lumion=本格的シネマティック演出 / Enscape=基本的なウォークスルーのみ / Twinmotion=Unreal Sequencerで高度なアニメ+Path Tracer ⚠️

### 2-2. Stable Diffusion + ControlNet(自前構築・完全自動化向け)

- 原理: ControlNetで構図をジオメトリで拘束し、プロンプトでスタイルだけ制御 ✅
  - **MLSD**(直線検出): 建物・インテリアの直線構造保持に最適。曲線は無視される ✅
  - **Canny**: 立面図・ファサードのエッジ保持 ⚠️ / **Depth**(Midas/Zoe/Depth Anything): 奥行き・ボリューム関係の保持 ✅
- 実務ワークフロー: Revit/SketchUp/AutoCADからビューを書き出し → AUTOMATIC1111 / ComfyUI に読み込み → ControlNet前処理 → プロンプト ⚠️。txt2img/img2img/inpaintの使い分け ⚠️
- コスト: ソフトは無料(オープンソース)。ローカル実行はNVIDIA GPU VRAM 8GB以上(快適には16GB)が必要 ⚠️。RunPod/Vast.ai等のクラウドGPUでも可 ⚠️
- 習得: 実用レベルまで数週間の練習が必要 ⚠️。建築家向け有償講座が成立する程度に確立した手法
- 機密性: ローカル実行なら顧客図面が外部に出ない(受託時の営業材料になる) ⚠️
- ライセンス注意: SD3以降のCommunity Licenseは年商$1M未満制限あり。SD1.5/SDXL系は制限なし。モデル系統ごとに商用条件の確認必須 ⚠️
- 限界: 「雰囲気パース」「初期デザインスタディ」用途が主。寸法精度・建築的整合性は保証されず、最終成果物には人のチェック・修正が必須 ⚠️

**評価**: パイプラインをAPI/スクリプトで完全自動化できる唯一の構成。ただし品質の安定化(プロンプト設計・LoRA・後処理)に技術投資が要る。

## 4. 画像→動画AI(静止パース→カメラモーション付き動画)

### API価格(image-to-video、2026年前半時点)

| モデル | 単価 | 10秒動画の原価 | 上限 | 検証 |
|---|---|---|---|---|
| **Runway Gen-4 Turbo** | $0.05/秒(5クレジット/秒、$0.01/クレジット) | **約$0.50** | 10秒 | ✅ 公式docs |
| **Kling 1.6** | $0.04/秒 | 約$0.40 | 10秒・720p | ⚠️ |
| **Luma Ray 2** | $0.08/秒 | (最大5秒) | 5秒・1080p | ⚠️ |
| **Runway Gen-4.5** | $0.12/秒 | 約$1.20 | — | ✅ 公式docs |
| **Google Veo 3/3.1**(音声付き) | $0.40/秒(Runway API経由) | 約$4.00 | 8秒前後 | ✅ 公式docs |
| **OpenAI Sora 2** | $0.60/秒 | 約$6.00 | 20秒・1080p | ⚠️ |

- Runwayクレジットは$0.01/クレジットで組織購入 ✅。静止画生成もGen-4 Imageが$0.05〜0.08/枚 ✅ → パース量産にも使える
- 主要6社(Sora/Runway/Veo/Kling/Luma/Pika)すべて公開APIあり=自動パイプライン組込可 ⚠️
- Kling 3.0はネイティブ4K/60fps・最大6カットのマルチショット対応 ⚠️。建築ではKling=モーション品質、Runway=制御性、Luma=自然なモーションという評価 ⚠️
- 注意: Runwayの旧モデル(Gen-3 Alpha Turbo等)は2026-07-30廃止 ✅ → API依存パイプラインはモデル更新への追従が必要

### 建築向けワークフローの定石 ⚠️

1. 元パースの下準備(アップスケール・色補正・不要物除去)。前景/中景/背景のレイヤーが明確な画像が最良
2. 空間に合わせたカメラモーション選択(リビング=ドリーイン、開放空間=横パン、注視対象=控えめオービット)
3. まず3〜6秒のテストクリップ → 良ければ本番
4. 長尺は「establishing shot→エントランス→主要空間→ディテール→締め」の複数ショット連結(1本の長回しはできない)
5. 失敗モード: 家具・壁の歪み、ガラス・反射のちらつき → 全件人間チェック必須

**評価**: フレーム単位の正確なカメラ制御はできないため「正確なウォークスルー」ではなく「シネマティックな雰囲気動画」。それでもSNS・プレゼン用途には十分で、原価は1本数十円〜数百円。

## 6. 結論: 小規模工務店・設計事務所向けサービスを組むなら

### 推奨構成(段階導入)

**フェーズ1: 受託サービス(ツール組合せ、開発ほぼ不要)**
- 入力: 客先の平面図・立面図(PDF/JPG/CAD)
- パース: ①既存3Dデータがあれば D5 Render(無料〜$360/年)/Twinmotion(無料)でレンダー、②図面のみなら Getfloorplan($25/件)で3D化 or SD+ControlNet/国産ArchiXで雰囲気パース
- 動画: 完成パースを Runway/Kling API に投げて10秒クリップ×3〜5本を連結(原価数百円)
- 想定売価: パース1〜2万円/カット、動画1.5〜3万円/本(従来相場の1/3〜1/10、ココナラ上位と同等価格で納期即日〜2日を差別化に)
- 原価構造: ツール費は月数千円+API従量。粗利のほぼすべてが作業時間

**フェーズ2: 半自動パイプライン(システム化)**
- Planner 5D Business API(平面図→3D自動認識、非同期API)+ レンダーAPI + Runway APIをつなぐWebアプリ化
- ただし: Planner 5D APIは営業経由・日本語UIなし ✅、Getfloorplanは人間QA挟み24時間 ✅ → **「完全自動・即時」は現状どのSaaSを使っても不可**。人間QAを挟む前提の「24時間納品サービス」が現実的な設計
- 完全自動を目指すならSD+ControlNet(自前GPU or RunPod)+ ComfyUIパイプラインの内製が必要(技術投資大、品質安定化が課題)

### 判断のポイント

1. **動画が一番「魔法に見えて」原価が安い**(9,800円で売って原価数百円)。ただしシェルパが同価格帯で先行 ✅ → 差別化は「パースから」ではなく「図面から一気通貫」+地域密着+工務店の営業フロー組込(LINEで図面送付→翌日動画納品、等)
2. AIパースの品質限界(寸法精度・建築的整合性)は全ソースが指摘 → 「実施設計の代替」ではなく**「営業・プレゼン用ビジュアル」に用途を限定**して売る
3. 生成物の商用利用条件・著作権はツールごとに要確認(生成画像の権利がAI提供元に帰属するケースの指摘あり ⚠️)
4. 従来型レンダラーのスキル(D5/Twinmotion)を1つ持っておくと、AIで対応できない「正確なパース」案件も受けられ、AI系との品質差も説明できる
