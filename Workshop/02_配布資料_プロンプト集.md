# そのまま使えるプロンプト集 — ランドスタイル版

【 】の中を自分の案件に置き換えて、コピペするだけです。
**お客様の氏名・住所・電話番号・契約内容は入れないでください。**（「A様」「◯◯市の物件」で伏せる）

---

## 使い方の原則（これだけ覚える）

1. **役割を与える** … 「あなたは新築戸建ての営業担当です」
2. **材料を渡す** … 間取り・立地・価格・お客様像。渡した情報の量で出来が決まる
3. **形を指定する** … 「300字で」「3案出して」「箇条書きで」

うまくいかないときは、**AIが悪いのではなく材料が足りない**。足す。

---

## 営業のかた

### ① 物件紹介文（SUUMO・自社HP）
```
あなたは新築戸建ての販売担当です。
以下の物件の紹介文を、SUUMO掲載用に300字で書いてください。
誇張はせず、実際に生活する場面が想像できる書き方にしてください。

【物件】所沢市◯◯町／土地◯◯㎡／建物◯◯㎡／4LDK／価格◯◯万円
【特徴】南向きリビング、駐車2台、駅徒歩◯分、小学校まで◯分
【想定するお客様】小学生の子どもがいる30代夫婦
```

### ② 同じ物件をお客様タイプ別に書き分ける（← これが一番効きます）
```
上の物件について、次の3タイプ向けにそれぞれ紹介文を書き分けてください。
それぞれ「何を一番の魅力として押し出すか」を最初に1行で書いてから、本文300字。

1. 小学生の子どもがいるファミリー
2. 共働きで通勤時間を重視する夫婦
3. 親との同居を検討している世帯
```

### ③ 追客メールの下書き
```
内見に来られたお客様へ送る、フォローのメール文面を作ってください。
売り込みが強すぎない、丁寧だが硬すぎないトーンでお願いします。

【状況】◯月◯日に◯◯の物件を内見／反応は良かったが決めきれていない
【伝えたいこと】追加で用意できる資料がある／他に検討中の物件があれば比較材料を出せる
【長さ】400字程度
```

### ④ 図面からセールスポイントを洗い出す
```
この間取りの物件について、営業として押すべきポイントを10個挙げてください。
そのうち「他社の物件と差がつくもの」に印をつけてください。
逆に、お客様から突っ込まれそうな弱点も3つ挙げてください。

【間取り】（間取り図の内容を文字で入力、またはPDF・画像を添付）
```

## 設計・建築のかた

### ① 専門用語をお客様の言葉に直す
```
以下の説明文を、建築の知識がないお客様にも分かるように書き直してください。
専門用語には短い言い換えを添えてください。意味は変えないでください。

【原文】（仕様書や説明文を貼り付け）
```

### ② 仕様書から設備一覧を作る
```
以下の仕様書から、住宅設備をメーカー・品番・場所ごとに表に整理してください。
記載がないものは「記載なし」としてください。推測で埋めないでください。

（仕様書を貼り付け、またはPDFを添付）
```

### ③ 施主への説明文
```
お施主様に、以下の内容を書面でご説明する文章を作ってください。
専門的すぎず、かつ誠実に伝わる書き方でお願いします。

【伝える内容】（例：仕様変更の理由と、それによる影響）
【長さ】500字程度
```

## 事務のかた

### ① 長い文書・メールを3行にする
```
以下の文章を3行で要約してください。
そのあとに「こちらが対応すべきこと」だけを箇条書きにしてください。

（メール・書類を貼り付け）
```

### ② 打合せの議事録にする
```
以下の打合せメモを、議事録の形に整えてください。
「決まったこと」「保留になったこと」「誰が何をいつまでにやるか」の3つに分けてください。
メモに書かれていないことは補わないでください。

（メモや書き起こしを貼り付け）
```

### ③ Excelで詰まったとき
```
Excelでやりたいことがあります。式を教えてください。
式だけでなく、何をしている式なのかも1行で説明してください。

【今のデータ】A列に日付、B列に物件名、C列に金額が入っています
【やりたいこと】物件ごとに金額を合計したい
```

### ④ 定型の連絡文
```
以下の内容を、社外向けの連絡メールにしてください。
件名も付けてください。丁寧すぎて長くならないようにしてください。

【伝えること】（箇条書きでOK）
【相手】（例：取引先の担当者）
```

## 社長・マーケティング

### ① Instagram の投稿ネタを一気に出す
```
埼玉県で新築分譲住宅を手がける工務店のInstagramアカウントを運用します。
一級建築士が女性であることを強みとして出したいです。
投稿ネタを30本、それぞれ「タイトル」と「何を見せるか」の2行で出してください。
売り込みではなく、家づくりを考えている人が保存したくなる内容にしてください。
```

### ② 滞留している物件の見せ方を変える
```
以下の物件が想定より長く売れ残っています。値下げ以外に打てる手を洗い出してください。
「見せ方の問題」「訴求相手の問題」「情報不足の問題」に分けて、それぞれ3つずつ挙げてください。

【物件】（概要・価格・掲載期間・反響の状況）
```

## うまくいかないときの直し方（3つだけ）

| 症状 | 直し方 |
|---|---|
| 当たり障りのない文しか出ない | **材料を足す**。間取り、立地、価格、お客様像を具体的に書く |
| 求めていた形と違う | **形を指定する**。「300字で」「表で」「3案」「箇条書きで」 |
| 惜しいけど違う | **やり直させる**。「もっとやわらかく」「専門用語を減らして」でそのまま続けて言う |

**AIは何度でもやり直させて構いません。**一発で完璧を狙わず、会話で近づけるのが正しい使い方です。

---

## 3つの約束

1. お客様の個人情報・契約情報は入れない
2. 数字・法令・物件情報は必ず自分で確認する
3. まずは**下書き**に使う。読まずにそのまま出さない
