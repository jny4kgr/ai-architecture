## 例1 ★本命★ 同じAIで、これだけ違う

> **この1本が今日の講習の核。**「AIがすごい」ではなく「渡す情報で決まる」を体で分からせる。

### ❌ 雑に頼んだ場合

**入力:**
```
新築戸建ての物件紹介文を書いてください。
```

**出力:**
> 陽当たり良好な新築一戸建てが誕生しました。落ち着いた住宅街に位置し、ファミリー層に最適な間取りをご用意。最新の住宅設備を備え、快適な暮らしをお約束します。周辺には生活に便利な施設が揃っており、通勤・通学にも便利な立地です。ぜひ一度、現地をご覧ください。

**→ どの物件にも使える。つまり、どの物件も売れない。**

### ⭕ 情報を渡した場合

**入力:**
```
あなたは新築戸建ての販売担当です。
以下の物件の紹介文を、SUUMO掲載用に300字で書いてください。
誇張はせず、実際に生活する場面が想像できる書き方にしてください。

【物件】埼玉県朝霞市浜崎3丁目／木造3階建／敷地82.64㎡・延床120.47㎡
【間取り】1階=ビルトインガレージ・6帖納戸・玄関収納・階段下収納
　　　　　2階=17帖LDK・洗面・浴室
　　　　　3階=洋室6帖・5帖・4.5帖＋バルコニー2面
【設備】クリナップの対面キッチン／TOTOサザナ1616（浴室暖房乾燥・追焚き）
　　　　LIXILの断熱玄関ドア（電池錠）／Low-Eペアガラス
【最寄】朝霞台駅（東武東上線）・北朝霞駅（JR武蔵野線）
【想定するお客様】小学生の子どもがいる30代の共働き夫婦
```

**出力:**
> 2階に17帖のLDKを配した、3階建ての住まいです。生活の中心を2階に置くことで、道路からの視線を気にせず過ごせます。キッチンは対面式。お子さまが宿題をする様子を見ながら、夕食の支度ができます。
>
> 1階にはビルトインガレージと6帖の納戸。ベビーカーも、季節家電も、キャンプ道具も、玄関のすぐ内側に収まります。3階は洋室が3室とバルコニーが2面。お子さまの成長に合わせて使い分けられます。
>
> 浴室には暖房乾燥機と追焚き機能。共働きで帰宅時間がずれるご家庭でも、いつでも温かいお風呂に入れます。朝霞台駅・北朝霞駅の2路線が使える立地です。

**→ 同じAI。違うのは、渡した情報の量だけ。**

### 当日の見せ方
2枚を並べて投影し、**先に何も言わずに読ませる。**「どっちが良いですか」と聞いてから種明かしする。
台詞: 「AIの性能の差じゃないんです。**こっちには物件のことを教えて、こっちには教えなかった。それだけです。**」

## 例2 1つの物件を、お客様のタイプ別に書き分ける

> ランドスタイルの差別化戦略「1物件をペルソナ別に多く見せる」の実演。**営業向けの本命。**

**入力:**
```
（例1と同じ物件情報を貼る）

この物件について、次の3タイプ向けに紹介文を書き分けてください。
それぞれ「何を一番の魅力として押し出すか」を最初に1行で書いてから、本文200字。

1. 小学生の子どもがいるファミリー
2. 共働きで通勤時間を重視する夫婦
3. 車が趣味で、駐車環境を重視する人
```

**出力:**

**① ファミリー向け** — 押し出す魅力: 子どもの成長に合わせて形が変わる家
> 3階の洋室3室が、この家の強みです。お子さまが小さいうちは1室を遊び場に、大きくなれば個室に。バルコニーが2面あるので、どの部屋にも風が通ります。2階の17帖LDKは対面キッチン。宿題を見ながら夕食の支度ができる距離感です。1階の6帖納戸には、自転車も、季節ごとの荷物も収まります。

**② 共働き夫婦向け** — 押し出す魅力: 朝と夜の時間を削らない設計
> 朝霞台駅と北朝霞駅、2路線が使えます。行き先が違うお二人でも、それぞれ最短の経路を選べます。浴室には暖房乾燥機。帰宅が遅くなっても追焚きで温かく、雨の日も洗濯物を気にせず出かけられます。買い物袋を持ったまま、ガレージから玄関へ直接入れる動線です。

**③ 車が趣味の人向け** — 押し出す魅力: 家の中にガレージがある生活
> 1階がビルトインガレージです。雨に濡れず乗り降りでき、夜間も人目を気にせず作業できます。ガレージの隣には6帖の納戸。工具もタイヤも、ここに置けます。生活空間は2階から上にまとめてあるため、車の出入りが家族の時間を邪魔しません。

### 当日の見せ方
「今、**同じ物件で3本**出しました。かかった時間は30秒です。SUUMOに載せるとき、どのお客様を狙うかで書き分けられます。」
→ そのままステップ13（掲載・配信）の話に繋げる。

## 例3 図面から、押すべき点と突っ込まれる点を洗い出す

> **ベテラン営業ほど刺さる。**「勘でやっていたことの抜け漏れチェック」という位置づけで見せる。

**入力:**
```
この物件について、営業として押すべきポイントを10個挙げてください。
そのうち「他社の物件と差がつくもの」に★をつけてください。
逆に、お客様から突っ込まれそうな弱点も3つ挙げ、それぞれへの答え方も添えてください。

（例1と同じ物件情報を貼る）
```

**出力:**

**押すべきポイント**
1. ★ 2階LDK17帖 — 道路からの視線が切れ、カーテンを開けたまま生活できる
2. ★ ビルトインガレージ — 雨天の乗り降り、防犯、車の保護
3. ★ 1階6帖納戸 — 3階建てで不足しがちな収納を1階にまとめて確保
4. 2路線利用可（東武東上線・JR武蔵野線）
5. バルコニー2面 — 洗濯物の逃げ場が2つ
6. 浴室暖房乾燥機＋追焚き — 共働き世帯の生活時間差に対応
7. Low-Eペアガラス＋樹脂アルミ複合サッシ — 冷暖房効率
8. 対面キッチン — 調理中も家族と視線が通る
9. ★ 3階に個室3室 — 子ども2人＋書斎、などの組み合わせが可能
10. 玄関収納・階段下収納 — 細かい収納が分散配置されている

**突っ込まれそうな弱点と、答え方**

| 弱点 | 答え方 |
|---|---|
| 3階建ては階段の上り下りが大変では | 生活の中心が2階なので、日常の移動は「2階の中」で完結します。3階は寝室と個室で、1日2往復程度です |
| 敷地82.64㎡は狭いのでは | 延床は120.47㎡あります。3層に分けることで、同じ土地でも部屋数と収納を確保しています |
| 庭がない | ガレージと2面のバルコニーが屋外space代わりです。庭の手入れの手間がない分、週末の時間が空きます |

### 当日の見せ方
**弱点3つの方を先に見せる。**「押しどころは皆さんの方が詳しいと思います。でも**突っ込まれる点を先に洗い出しておくのは、AIが得意**です。」

## 例4 専門用語を、お客様の言葉に直す【設計向け】

**入力:**
```
以下の設備仕様を、建築の知識がないお客様にも伝わる説明文に直してください。
「それが自分の生活にどう効くのか」が分かるようにしてください。事実は変えないでください。

・Low-Eペアガラス／LIXIL サーモスA
・エコジョーズ24号オート
・TOTO サザナ1616 浴室換気暖房乾燥機付・追焚き機能
・クリナップ KT フラット対面キッチン
```

**出力:**

| 仕様 | お客様への説明 |
|---|---|
| Low-Eペアガラス／サーモスA | 窓ガラスが2枚重ねになっていて、間に特殊な膜が入っています。**冬は暖房の熱が逃げにくく、夏は外の熱が入りにくい**構造です。窓際の寒さや結露が出にくくなります |
| エコジョーズ24号オート | 給湯器です。**24号は、シャワーとキッチンを同時に使ってもお湯の勢いが落ちない**サイズ。エコジョーズは従来より少ないガスで同じ量のお湯を沸かせるため、ガス代が抑えられます |
| サザナ1616／浴室暖房乾燥・追焚き | 1616は**1.6m×1.6mの浴室サイズ**。一般的な戸建てで最も多く、大人が足を伸ばせます。暖房乾燥機は、冬の入浴前に浴室を暖められ、雨の日は洗濯物も乾かせます |
| フラット対面キッチン | キッチンとダイニングの間に**壁や段差がない**形です。料理をしながらお子さまの様子が見え、配膳もそのまま渡せます |

### 当日の見せ方
「**設計の方には当たり前でも、お客様には通じない言葉**があります。これ、いちいち書き直すの面倒じゃないですか。」

## 例5 長いメールを、3行と「やること」に変える【事務向け】

> **事務職を置いていかないための枠。**全社員向けなので、ここを飛ばすと半分の人が他人事になる。

**入力:**
```
以下のメールを3行で要約してください。
そのあとに「こちらが対応すべきこと」だけを、期限つきの箇条書きにしてください。
書かれていないことは補わないでください。

（実際の長文メールを貼る）
```

**出力（例）:**
> **要約**
> 1. 瑕疵保険の現場検査日程について、希望日の再提出を求められている
> 2. 提出書類のうち、配筋写真の一部が不鮮明で差し替えが必要
> 3. 検査後の完了報告書の様式が今年度から変更になっている
>
> **こちらが対応すること**
> - [ ] 検査希望日を第3希望まで返信（今週金曜まで）
> - [ ] 配筋写真の撮り直し分を送付（検査日の3営業日前まで）
> - [ ] 新様式の完了報告書をダウンロードして差し替え（期限の記載なし）

### 当日の見せ方
**【準備】実際の長文メールを1通用意する**（社外秘の部分は伏せる。無ければ一般的な業務メールで代替）。
台詞: 「**読むのが仕事じゃなくて、対応するのが仕事**ですよね。読む部分をAIに渡せます。」

## 例6 周辺環境の「紙」を作る

> ここから地図の話（B・仕組み）に繋げる。

**入力:**
```
以下の物件について、販売資料に載せる「周辺環境」のページの文章を作ってください。
距離や所要時間は、私が渡した情報にあるものだけを使ってください。
情報が無いものは「（要確認）」と書いて、勝手に補わないでください。

【物件】埼玉県朝霞市浜崎3丁目
【周辺】スーパーみらべる北朝霞店／朝霞第七小学校／朝霞第二中学校
【最寄】朝霞台駅（東武東上線）・北朝霞駅（JR武蔵野線）
```

**出力:**
> **暮らしの周辺**
>
> 日々の買い物は、スーパーみらべる北朝霞店（徒歩　分・**要確認**）。
> お子さまの通学は朝霞第七小学校（徒歩　分・**要確認**）、朝霞第二中学校（徒歩　分・**要確認**）。
> 最寄りは朝霞台駅（東武東上線）と北朝霞駅（JR武蔵野線）の2駅で、2路線が使えます（それぞれ徒歩　分・**要確認**）。

### 当日の見せ方
「**ちゃんと『要確認』で止まりました。**渡していない情報は、書かないように指示できます。

ただ、**この空欄を埋めるのが毎回めんどくさいですよね。**物件を全部地図で持っておけば、この距離は自動で出せます。それが後半で話した『仕組みを作る』方の話です。」

→ **スライド13（B）の物件マスタ＋地図に接続する。**

## 例7 ⚠️ 危ない使い方の実演（ハルシネーション）

> **必ずやること。**これを見せずに帰すと、誰かが事故を起こす。

**入力:**
```
埼玉県朝霞市浜崎3丁目の新築戸建ての紹介文を書いてください。
駅からの距離や周辺環境も入れて、魅力的にお願いします。
```

**出力（※これは捏造された内容です）:**
> 東武東上線「朝霞台駅」より徒歩**8分**。JR武蔵野線「北朝霞駅」も徒歩**10分**の好立地。周辺にはスーパーマーケットが徒歩**5分**圏内に複数あり、小学校まで**徒歩7分**と、お子さまの通学も安心です。閑静な住宅街に位置し……

**この徒歩分数は、AIが勝手に作ったものです。**こちらは一度も教えていません。

### 当日の見せ方（ここが山場）
1. まず出力を読ませる。**それらしく見えることを確認させる**
2. 「**この数字、私は一度も教えていません。**AIが作りました」
3. 「**なぜこうなるか。**AIは調べているのではなく、**それらしい続きを作っている**からです。朝霞市の物件の紹介文なら、だいたい徒歩8分くらいって書いてあるよね、と」

**台詞の締め:**
「だから今日の約束の2番、**数字と法令は必ず自分で確認する。**これだけは守ってください。**徒歩分数を間違えて広告に出したら、事故です。**

逆に言うと、例6のように『**渡した情報だけで書いて、無いものは要確認と書いて**』と指示すれば、防げます。」
